# ByteFuturo

Projeto acadêmico de desenvolvimento front-end para uma organização social fictícia chamada **ByteFuturo**, criada com o objetivo de ampliar o acesso à tecnologia e à educação digital.

A aplicação apresenta iniciativas da ONG, informações sobre participação e doações e uma área de cadastro. O projeto foi desenvolvido como uma SPA (Single Page Application) utilizando HTML, CSS e JavaScript puro.

## Objetivo

O projeto busca aplicar, em um cenário próximo ao mercado, conceitos de desenvolvimento front-end, organização de código, responsividade, acessibilidade, versionamento e preparação para publicação em ambiente de produção.

## Funcionalidades

- Navegação entre seções sem recarregar toda a página;
- Página inicial com apresentação da ByteFuturo;
- Área de projetos e iniciativas;
- Informações sobre doação e voluntariado;
- Formulário de cadastro;
- Máscaras e validações de campos;
- Menu responsivo para dispositivos móveis;
- Feedback visual após envio do formulário;
- Estrutura preparada para melhorias de acessibilidade.

## Tecnologias utilizadas

- **HTML5** — estrutura e semântica das páginas;
- **CSS3** — layout, responsividade e estilos visuais;
- **JavaScript** — roteamento, interações, validações e comportamento da interface;
- **Git** — controle de versão;
- **GitHub** — hospedagem do repositório, gestão de branches, issues e pull requests.
